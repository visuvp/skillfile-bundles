# SkillFile Bundles

## Project Overview
SkillFile Bundles is a web application that showcases a variety of digital products including eBooks and templates. Users can browse products, add them to their cart, and view the cart contents. The application is built using HTML, CSS (Tailwind CSS), and JavaScript.

## Installation
To run SkillFile Bundles locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/skillfile-bundles.git
   ```
2. Navigate into the project directory:
   ```bash
   cd skillfile-bundles
   ```
3. Open the `index.html` file in your preferred web browser.

## Usage
Once you have the application open in your browser:

- Browse through the displayed products.
- Click on the "Add to Cart" button to add items to your cart.
- Click on the shopping cart icon to view your cart.
- You can proceed to checkout or clear your cart if needed.

## Features
- Dynamic product listing with images, titles, and pricing.
- Cart functionality allowing users to add and remove items.
- Responsive design with Tailwind CSS for optimal viewing on various devices.
- Modal for displaying cart details and totals.

## Dependencies
The project relies on the following dependencies:
- **Tailwind CSS**: For styling the application using utility-first CSS.
- **Font Awesome**: For icons used within the application.
- **Google Fonts**: Specifically, the 'Inter' font family for text styling.

These dependencies are included via CDN links in the `index.html` file.

## Project Structure
The project is organized as follows:
```
skillfile-bundles/
├── index.html          # Main HTML file
├── script.js           # JavaScript file for product handling and cart functionality
└── styles.css          # Custom CSS styles
```

### File Descriptions:
- **index.html**: Contains the structure of the web application, including the header, main content, cart modal, and footer. It links to external styles and scripts.
- **script.js**: Contains JavaScript logic for managing products, displaying them, handling cart actions, and updating the user interface dynamically.
- **styles.css**: Defines custom styles that enhance the default styling provided by Tailwind CSS.
